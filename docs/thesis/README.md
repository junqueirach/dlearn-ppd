# 2001 thesis

* `junqueira-2001-geracao-arquivos-dados-software-analise-estrutural.pdf` — the original (Portuguese)
* [`thesis-en.md`](thesis-en.md) — English translation of the main text, with 2026 notes and a map of the annexes to the repository

Luiz Eduardo Lollato Junqueira, **Geração de arquivos de dados para software de análise
estrutural** (Data-file generation for structural-analysis software). Trabalho de
graduação, Engenharia Civil, Faculdade de Engenharia de Bauru, UNESP, dezembro de 2001.
Orientador: Prof. Dr. Heitor Miranda Bottura. 100 pages, Portuguese.

Contents: finite-element and structural-dynamics background, DLEARN and its input
format, the Hermitian solution path (K and M assembled separately, [M]⁻¹[K], the
order-dependent system, consistent accelerations from the equilibrium equation), the
Turbo Pascal implementation, a worked truss example, and in the annexes the complete
DLEARN variable list (pp. 1–16), the PPD source listing (pp. 17–75) and the example
input and output files (pp. 76–100).

Note: the column positions of IHERM and of the load-time-function card in the annex
are wrong, and the gravity card is treated as optional — see
[`../dlearn-input-format.md`](../dlearn-input-format.md), "Known errors".
